# 地脉簿使用说明

[打开 PWA](https://shuxiachai.github.io/LeyLineBook/) · [下载 Windows 最新版](https://github.com/shuxiachai/LeyLineBook/releases/latest) · [返回项目首页](../README.md)

## 选择使用方式

- **电脑：** 在最新 Release 的 Assets 中下载 `LeyLineBook-v版本号-Windows-x64.exe`，双击运行，无需安装 Python。不要把源码压缩包当作 Windows 程序。
- **手机：** 联网打开 PWA，按浏览器菜单选择“添加到主屏幕”或安装应用。首次加载并完成资源缓存后可离线使用；不同浏览器和设备的安装入口可能不同。
- Windows 程序尚未提供代码签名，系统可能拦截。请核对仓库及发布文件来源；不建议为运行它关闭系统安全防护。

## 从第一个账号开始

1. 打开“号主与任务”，新增账号，填写便于自己识别的名称。
2. 按实际需要启用体力、狗粮、深渊、剧诗等任务；多个账号可分别配置。
3. 回到“今日任务”，查看各账号待办，做完后点击对应任务记录完成。
4. 误点时再次点击已完成任务撤销。间隔、月度和版本周期任务须从最新记录开始撤销；补记前先确认页面日期。
5. 剧情委托、限时活动分别在对应页面管理。完整规则可查看应用内“使用说明”。

这些操作只记录你已经做过的事情，**不会连接游戏、登录游戏账号或自动完成游戏任务**。

## 电脑与手机之间迁移

**两端各自保存数据，不会自动同步，也不提供跨设备合并。** Windows 任务库保存在本机 SQLite 中，PWA 任务库保存在当前浏览器的 IndexedDB 中。

1. 在来源设备打开“设置与备份”，选择“导出备份”，保留生成的 JSON 文件。
2. 将该文件自行传到目标设备。备份可能含账号昵称、备注和任务记录，请通过自己信任的方式传输，不要公开上传。
3. 如果目标设备已有记录，先在目标设备导出一份备份，避免覆盖其独有内容。
4. 确认两端版本支持相同的备份格式，再在目标设备选择“导入备份”并确认。
5. 导入后核对账号、任务和完成记录。**导入替换目标设备当前数据，不是把两份数据合并。**

不要在两端各自修改后反复互相覆盖。选择一端作为当前主要记录端，再将完整备份迁移到另一端；原设备的数据不会因为另一端修改而变化。

## 备份与恢复

- 导入前两端都会保存快照。PWA 可在“设置与备份”的“导入前快照”中恢复最近保留的 5 份；桌面端的 `pre-import-日期时间.json` 位于数据目录，可通过导入该文件恢复。
- 快照仍在当前设备内，不能代替另存到设备外的备份。清除浏览器网站数据、丢失设备或删除数据库都可能造成数据丢失。
- JSON 备份**不包含账号密码等凭据**。PWA 不存储凭据；Windows 凭据仅能由原 Windows 用户和设备解密，不能依靠普通 JSON 备份跨设备迁移。
- v3.0.5 使用备份格式 3；v3.0.4 及更早版本不能导入该格式。跨端迁移前请查看[更新日志](../CHANGELOG.md)及导入端版本。
